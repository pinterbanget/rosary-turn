# Rosary Turn

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

People praying the Rosary while Claude Code or Codex works during coding sessions.

## Product Purpose

A Rosary adaptation of Rizaldy's Quran Turn, with the OpenRosary web experience reproduced from the user's existing repository.

## Operating Context

Local browser reader, opened by agent session hooks. Progress survives turns and restarts. The daily mystery follows OpenRosary's suggested days. The upstream repository remains visible as the fork parent.

## Capabilities and Constraints

Full Rosary sequence and Scripture readings, English and Indonesian, optional Latin prayers, light and dark themes. Preserve the upstream offline runtime, native curtain hosts, and quiet hook behavior. No account, telemetry, donation service, or external runtime network requests.

## Brand Commitments

User explicitly requests a 1:1 OpenRosary web feel. Original Quran Turn authorship and license must remain clear.

## Evidence on Hand

Quran Turn source from https://github.com/rzrizaldy/quran-turn. OpenRosary web source at ../openrosary-web and Android source at ../openrosary.
